# Shamela Salaf Research

Корпусный поисковик для исследования ранних формул **فوق العرش / بائن من خلقه / مباين للخلق** и вопроса, понимали ли их ранние суннитские авторитеты пространственно.

Источник данных: `AuthenticIlm/Shamela4_Full_DB` на Hugging Face — полный экспорт Shamela 4 (8 589 книг, ~7.6 млн страниц, ~19.8 ГБ текста).

## Что делает

Сканер ищет не одну фразу, а сразу сеть формулировок:

- утверждение: `بائن من خلقه`, `مباين للخلق`, `فوق العرش`, `على العرش` и варианты;
- антипространственная лексика: `لا بمسافة`, `لا بعزلة`, `لا بمكان`, `لا بجهة`, `لا يحويه مكان`, `لا بمماسة` и т. п.;
- контрольная пространственная лексика: `مسافة`, `مكان`, `جهة`, `حيز`, `خارج العالم`, `التباعد` и т. п.;
- имена ранних авторитетов, чтобы находить их цитаты **в поздних книгах**, а не только в сохранившихся собственных трудах.

Арабский текст нормализуется для поиска: снимается ташкиль, унифицируются варианты алифа/йа, но в результат сохраняется исходный арабский текст.

## Установка

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -e .
```

## 1. Посмотреть категории

```bash
shamela-research categories
```

## 2. Самая важная выборка: прямые ранние авторы до 300 г.х.

Сканируем **все книги авторов, умерших до 300 г.х.**, независимо от категории:

```bash
shamela-research scan \
  --death-max 300 \
  --workers 8 \
  --output results/direct_pre300
```

Сначала стоит посмотреть классы `A_ATTRIBUTED_ANTI_SPATIAL` и `A_ANTI_SPATIAL`.

Только максимально прямые места с антипространственной лексикой:

```bash
shamela-research scan \
  --death-max 300 \
  --only-anti \
  --workers 8 \
  --output results/direct_pre300_anti
```

## 3. Ключевой режим: поздние книги, сохраняющие слова саляфов

Это важнее обычного фильтра по году смерти автора: слова имама II–III века могли сохраниться у аль-Лялякаи, Ибн Батты, аль-Байхаки, аз-Захаби, Ибн Таймии и т. д.

Начать разумно с категории акыды:

```bash
shamela-research scan \
  --category العقيدة \
  --require-name \
  --workers 10 \
  --output results/transmitted_aqida
```

Для максимально полного исследования убрать фильтр категории и просканировать весь корпус:

```bash
shamela-research scan \
  --require-name \
  --workers 10 \
  --output results/transmitted_full
```

Это потенциально скачает большую часть корпуса (~19.8 ГБ) в локальный кеш Hugging Face.

## 4. Искать только сильные антипространственные кандидаты

```bash
shamela-research scan \
  --require-name \
  --only-anti \
  --workers 10 \
  --output results/salaf_anti_spatial
```

Искомый идеальный результат выглядит примерно так:

- рядом имя саляфа;
- `بائن من خلقه` / `فوق العرش`;
- рядом `لا بمسافة` / `لا بعزلة` / `لا بمكان` / эквивалент.

## 5. Контроль: искать противоположную сторону

Нельзя делать одностороннюю подборку. Поэтому отдельно запускается поиск пространственной лексики рядом с теми же ранними именами:

```bash
shamela-research scan \
  --require-name \
  --only-spatial \
  --workers 10 \
  --output results/salaf_spatial_control
```

После ручной проверки это позволит понять, существовали ли в ранней традиции обе интерпретации.

## Классы результатов

- `A_ATTRIBUTED_ANTI_SPATIAL` — рядом раннее имя + антипространственная формула. **Главный приоритет.**
- `A_ANTI_SPATIAL` — сильная антипространственная формула без найденного имени.
- `B_ATTRIBUTED_UNRESOLVED` — имя саляфа + `بائن/فوق`, но без явного решения вопроса пространства.
- `C_ATTRIBUTED_SPATIAL_CONTEXT` — имя саляфа + пространственная терминология. Требует очень осторожной ручной проверки отрицаний и контекста.
- `C_SPATIAL_CONTEXT` — пространственная терминология без раннего имени.
- `D_UNRESOLVED` — обычное совпадение.

**Важно:** наличие слова `مسافة` ещё не означает утверждение расстояния: это может быть `لا بمسافة`. Поэтому классы — только сортировка кандидатов, а не готовый богословский вывод.

## Результаты

В `--output` создаются:

- `hits.jsonl` — удобен для дальнейшей машинной обработки;
- `hits.csv` — удобно сортировать вручную;
- `summary.json` — количество совпадений по классам.

Каждый hit содержит книгу, автора, год смерти автора, категорию, часть/страницу, путь исходного файла, найденные термины и арабский контекст.

## Что проверять вручную

Для каждого сильного кандидата:

1. Кто именно говорит: автор книги или цитируемый ранний имам?
2. Есть ли иснад/источник передачи?
3. Не являются ли слова частью реплики оппонента?
4. Не относится ли `مكان/مسافة/جهة` к чему-то другому?
5. Есть ли отрицание в предыдущем предложении?
6. Насколько ранний источник, через который дошла цитата?
7. Есть ли альтернативные версии текста.

Цель проекта — **найти кандидатов, которые обычный веб-поиск пропускает**, а не автоматически объявлять каждое совпадение доказательством.
